# J Lancaster Chimney Sweeps

Standalone static website, prepared from V3.2. No UKJSFG assets, configuration, or repository links.

## Publish on GitHub Pages
1. Create a **new** repository named `j-lancaster-chimney-sweeps` (do not use the UKJSFG repository).
2. Upload `index.html`, the entire `assets/` folder, and `.nojekyll` to the **root** of the new repository.
3. In that repository, go to **Settings → Pages → Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
4. GitHub will display your website URL after publishing.

**Before public launch:** Confirm all business details and telephone numbers, service claims, photo permissions and any prices. Do not point the existing business domain to the new website until its owner approves.

This package does not modify any existing repository or domain.
